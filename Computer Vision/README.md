# Camera Calibration Project

This repository contains the implementation and report of a camera calibration project based on Zhang’s method, developed for the course *Computer Vision and Pattern Recognition (554SM – Fall 2025)* at the University of Trieste.

The project includes:

- **Two Python notebooks/scripts** implementing the full calibration pipeline (corner detection, homography estimation, intrinsic and extrinsic parameter recovery, reprojection error analysis, stability study, and pose comparison).
- **A final PDF report** summarizing the methodology, mathematical derivations, implementation details, experimental results, and validation procedures.

Both code implementations produce consistent results and were merged into a unified final report.
